# DLS Hub — Dream League Soccer Community

Powered by Supabase (auth, database, storage).

## Setup
1. Create a Supabase project at supabase.com
2. Run `setup.sql` in SQL Editor
3. Run `rls_policies.sql` in SQL Editor
4. Create storage bucket `uploads` (public)
5. Paste your Supabase URL + anon key in `public/js/supabase-config.js`
6. Deploy to Vercel
